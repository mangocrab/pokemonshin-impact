# 다음 개발 계획

작성: 2026-11-04 (한국 시간) · 기준 커밋: `ce10ee8`

사용자 우선순위는 **아트 마감 → 추가 콘텐츠 → 밸런스**다. 이 파일은 앞으로 할 작업과 완료 기준을 관리하고, [ROADMAP.md](ROADMAP.md)는 실제 구현·검증 이력을 기록한다. 구현하지 않거나 검사하지 않은 항목을 완료로 표시하지 않는다. 날짜 대신 아래 순서와 의존 관계로 진행한다.

## 현재 기준

- 개인 월드, 계정 저장, 최대 4인 방문/협동, 권한 검증, 전투/성장/학습/수집은 유지한다.
- 8인 초상화·공통 여행자 4방향 보행, 개별 프로시저럴 노멀/그림자, 8인 궁극기 문양과 9종 기술 동작까지 적용했다.
- 캐릭터마다 다른 탐험 아바타, 신규 캐릭터 동작 프레임, 개별 기술 투사체/행동 순서, 캐릭터 음성은 남아 있다.
- 서버 검사 목록 141개, 브라우저 목록 48개다. 최근 아트 배치는 관련 항목을 선택 검사했으며 전체 48개를 매번 재실행한 것은 아니다.
- 실기기 FPS·메모리와 브라우저별 최종 검수는 미완료다.

## A. 아트와 표현 마감

|---|---|---|

A1은 현재 확정 기술 기록을 바로 활용할 수 있어 먼저 진행한다. A2는 1명 시범의 그림체·프레임 일관성을 확인한 뒤 확대하며, 기존 8명 초상화를 재색칠한 것으로 고유 보행 제작을 대체하지 않는다. 미세 조정만 반복하지 않고 각 작업에서 플레이어가 확인할 수 있는 산출물을 남긴다.

아트 산출물과 검증 상태를 먼저 정리하고, 아래 콘텐츠를 작은 완결 단위로 추가한다. 기존 탐험/부탁/보상/협동 기능을 삭제하지 않는다.

| B4 | 반복 도전·이벤트 구조와 안내/도감 보강 | 반복/일회성 보상 구분, 저장/기간/복구 검증. 현금 결제는 추가하지 않음 |

## C. 밸런스

1. 현재 수치·콘텐츠·성장 구간의 기준 결과를 저장하고 고정 시드로 재현 가능한 전투 시뮬레이션을 보강한다.
2. 단기/장기, 유리/불리 속성, 자속, 상태 면역, 일반/보스, 1인/4인, 같은 캐릭터 중복 편성을 비교한다.
3. 안정형/고위력/행동 불가/상태/지속 피해/준비 기술의 기대 피해와 잃는 행동 가치를 함께 측정한다. 모든 상황에서 우월한 기술이 생기는지 확인한다.
4. 레벨·돌파·무기·기술 해금·재화 획득 속도와 뽑기/천장/중복 해방 상한을 별도로 평가한다. 확률·보장 규칙을 표시한 내용과 일치시킨다.
5. 변경 전후 표와 근거를 남기고 서버 계산·성장·재화·기술 재습득·협동 보상 회귀를 통과한 데이터만 반영한다.

## 작업마다 지킬 절차

- 작업 시작 시 이 계획의 상태와 실제 저장소 상태를 확인한다.
- 구현 → 관련 서버/브라우저 검사 → 빌드 → 적용 화면 또는 확인 가능한 산출물 → 한계/남은 작업 기록 순서로 진행한다.
- 검증 범위를 정확히 기록한다. 선택 검사 통과를 전체 검사 통과나 실기기 인증으로 보고하지 않는다.
- 원본 아트, 서버 권한, 계정/월드 데이터, 기술 해금 기록과 현재 4슬롯 분리, 난수/재화 중복 방지를 보존한다.
- 사용자 지시에 따라 검증된 변경을 GitHub `main`에 반영하고 로컬/원격 커밋 일치와 작업 폴더 상태를 확인한다.
