# 소라빛 여름 — 구현 계약과 진행 상태

사용자 요구사항을 단계별로 구현한다. 이전 기능을 삭제하지 않으며, 미구현 기능은 UI와 보고서에서 완성으로 표시하지 않는다. 각 단계의 회귀 테스트를 통과한 뒤 다음 단계로 진행한다.

## 기술 및 콘텐츠 계약

- React / TypeScript / Vite / Phaser 4 / HTML·CSS / WebGL, PC·모바일 지원.
- Node.js / TypeScript / Socket.IO / PostgreSQL / Prisma. 중요한 상태·보상·확률·전투는 서버 권한.
- 독창적 여름 휴양지 탑뷰 2D 세계. 해변 마을, 야자수 숲, 산호 해안, 항구. 노멀맵·조명·그림자·높이·Y정렬·파도·식생·환경 효과 및 저사양 옵션.
- 회원가입·로그인·자동 로그인·로그아웃·닉네임. 안전한 해시, 보호 쿠키, 서버 세션. 캐릭터·무기·재화·인벤토리·기술·성장·월드·뽑기·설정 영구 저장.
- 기본 개인 월드. 상자·퀘스트·퍼즐·일회성 오브젝트·지역 해금·탐험 진행도 독립 저장.
- 소유자 포함 최대 4명, 친구 초대·수락, 진입 신청·승인·거절. 초대 전용/신청 허용/차단 설정. 방문자는 탐험·전투·NPC·개인 전투 보상 가능. 타인 상자·일회성 보상·퀘스트 완료·퍼즐·영구 진행도·소유물 수정 불가. 서버 검증. 호스트 종료 시 방문자 개인 월드 복귀.
- 메뉴: 시작, 캐릭터, 강화, 뽑기, 인벤토리, 친구·멀티, 설정. 모두 실제 데이터 연결.
- 소라: 뽑기 160/1회, 1600/10회. 퀘스트·탐험·업적·이벤트 보상. 조개: 레벨·돌파·기술·무기 성장. 현금 결제 없음.
- 초기 캐릭터 8명(여6/남2), 4·5성만. HP/공격/방어/스피드/치확/치피/속성 피해·저항/궁극기 에너지 및 개별 성장 계수.
- 불·물·바람·번개·얼음·자연. 상성 데이터 분리. 동일 속성 직접 공격 및 공격 궁극기 자속 1.5배. 회복·보호막·상태 확률·지속 피해에는 자동 적용하지 않음.
- 캐릭터별 일반 기술 최대4 + 패시브1 + 궁극기1. 해금 기록과 장착 슬롯 분리. 레벨별 해금, 학습 보류, 나중에 재습득, 교체 확인, 교체 후에도 해금 유지, 재접속 유지.
- 기술 데이터: ID/이름/설명/속성/분류/위력/명중률/상태 종류·확률·기간/우선도/대상/패널티·기간/요구 레벨/특수 효과/쿨다운. 고레벨 기술도 안정형을 완전히 대체하지 않음.
- 위험·보상 유형: 안정형80/100%, 고위력120/80%, 초고위력180/100%+다음 라운드 행동불가, 상태확정45/90%, 상태75%65/95%, 지속피해25/90%, 비공격상태0/85%는 초기 예시. 명중·상태 확률 개별 판정. 상태는 기술에 명시된 경우만 적용.
- 패널티: 낮은 명중, 다음 라운드 행동불가, 능력치 감소, 반동, 준비 행동, 쿨다운, 조건부 사용. 큰 패널티에 충분한 보상. 단기/장기/상성/자속/면역/보스/1인/4인 밸런스 검증.
- 화상·감전·빙결·둔화·속박·공격/방어/명중 감소. 기간·발동 시점·해제·중첩·면역·저항은 서버 처리. 강력한 행동제한의 중복·면역 규칙 별도.
- 최대4명 편성, 출전1/대기3. 교체는 행동1회, 편성·생존·행동제한 확인. 각 참가자는 자기 캐릭터만 제어.
- 전원 행동 선택 → 우선도/스피드/동률 정렬 → 1회 실행 → 지속 피해/상태/버프/패널티 갱신 → 승패/보상 → 다음 라운드. 기술·궁극기·교체·아이템·방어·조건부 도주. 1R 초고위력 → 2R 행동불가 → 3R 복귀. 제한 중 다른 참가자 진행 유지. UI와 서버 모두 제한.
- 뽑기 서버 RNG: 3성 무기만, 4성 캐릭터/무기, 5성 픽업/비픽업 캐릭터·무기. 기본0.6%/5.1%/94.3%, 10회4성 이상/90회5성, 픽업50%, 실패 시 다음5성 픽업 확정. 배너별 설정·기록·천장 저장.
- 첫 획득 해금, 2~7번째 전용 해방재료 각1(평생 최대6), 8번째 이후 별도 중복 보상. 최대6단계 해방, 단계별 고유 효과.
- 경험치/조개 레벨업, 레벨 제한 돌파에 캐릭터별·공통 재료. 3/4/5성 무기, 공격·부옵·효과·강화·장착이 전투 반영.
- 모든 재화·뽑기·성장·보상에 트랜잭션/중복 요청 방지. 클라이언트 값을 신뢰하지 않음.

## 필수 인수 테스트

현재 테스트는 `server/src/*.test.ts`. 전체 39개 인수 기준 중 일부만 구현했다. 미구현 항목을 통과로 간주하지 않는다.

- 계정·월드: 자동 로그인, 진행도 분리, 초대·신청, 4인, 방문자 상자·진행도 금지.

- 기술: 개별 위력, 명중 성공/실패, 명시적 상태, 별도 명중·상태 판정, 고위력 패널티, 다음 라운드 불가/복귀, 지속 피해/기간, 반동/능력치감소, 면역/해제.
- 학습: 레벨 해금, 저레벨 금지, 보류, 재습득, 최대4, 교체, 해금유지, 잊은 기술 재습득, 재접속 유지.
- 수집: 3성무기, 4성캐릭터/무기, 픽업/천장, 첫 획득 해금, 중복재료, 최대6, 개별 돌파재료, 서버 재화 검증.

## 알려진 제한

현재 그림은 프로시저럴 초기 아트다. 지형 노멀맵/동적 조명은 제공하지만 캐릭터·건물 노멀맵과 정교한 투영 그림자·완성 아트는 없다. 이동 위치는 2초 주기 및 접속 종료 시 저장된다. 정상 종료는 마지막 위치를 저장하며 강제 종료 시 마지막 저장 이후 최대 약 2초의 이동은 유실될 수 있다. 현재 단일 서버 프로세스 기준이며 다중 서버 이동 동기화는 미구현이다. 세션은 30일 만료, 운영 HTTPS에서 Secure 쿠키 사용. 운영 서비스 전에는 배포 출처 설정, 분산 요청 제한, 세션 정리, 비밀번호 복구와 보안 검토가 필요하다. 캐릭터 메뉴는 보유 캐릭터·편성·기초 능력치·기술을 실제 DB와 연결한다. 성장·학습은 캐릭터 메뉴, 조개 강화·돌파·해방·뽑기·장비는 강화/뽑기/인벤토리 메뉴의 실제 데이터와 연결한다. 설정 메뉴는 계정별 그래픽/움직임/음량을 저장하고 실제 적용한다. 친구·멀티플레이 메뉴는 실제 서버 데이터와 연결한다. 현재 결과를 전체 게임 완성으로 보고하지 않는다.
