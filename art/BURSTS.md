# 8인 궁극기 문양 컷인

기존 초상화에 캐릭터별 벡터 문양과 짧은 동작을 더했습니다. 원본 PNG/WebP를 다시 칠하거나 캐릭터 비례를 바꾸지 않으며, 남색·금색 배경과 6종 속성 색상을 유지합니다. 같은 속성인 루나/여하, 소미/이준도 서로 다른 모양과 움직임을 사용합니다.

| 캐릭터 | 문양 | 동작 |
|---|---|---|
| 해린 | 파도·물방울 | 물결이 올라오며 확장 |
| 루나 | 깃결 | 가볍게 회전하며 펼침 |
| 소미 | 잎·줄기 | 아래에서부터 잎을 펼침 |
| 태오 | 노을 검광 | 대각선으로 지나가는 검광 |
| 미라 | 번개·별자리 | 번개 윤곽선을 따라 그리기 |
| 나리 | 얼음 결정 | 작은 결정이 회전하며 성장 |
| 여하 | 돛·구름 | 바람을 따라 옆으로 이동 |
| 이준 | 뿌리·수호 인장 | 밑동에서 위로 세우기 |

문양 동작은 1.6초, 보조 선/별은 1.7초 동안 한 번 재생합니다. 기존 컷인의 1.8초 등장/퇴장과 2.2초 제거를 유지하며 새 타이머나 서버 대기를 추가하지 않습니다. 문양은 글자 뒤에 옅게 배치하고 작은 화면에서는 크기와 밝기를 줄입니다. 전체 컷인의 `pointer-events:none`을 유지해 다음 행동을 막지 않습니다.

## 실행·설정

- 기존 서버 스냅샷의 라운드 증가와 궁극기 에너지 소비를 확인한 뒤 표시합니다. 기술 선택이나 협동 대기만으로 재생하지 않으며, 첫 로딩·중복·이전 버전·여러 라운드를 건너뛴 복구에서는 과거 효과를 반복하지 않습니다.
- 계정의 움직임 줄이기와 기기의 `prefers-reduced-motion`을 따릅니다. 멈춘 상태에서도 초상화·문양·기술명은 읽을 수 있습니다.
- 저품질 또는 환경 효과 끄기에서는 문양과 초상화를 숨기고 기술명/캐릭터명은 유지합니다. SVG 구성 자체를 생략하는 방식은 아니며 CSS에서 표시·동작을 제어합니다.
- 추가 이미지 다운로드나 DB 변경은 없습니다. WebP 6종 약 1.89MiB와 14개 마이그레이션을 유지하며 벡터 경로와 CSS가 클라이언트 코드에 추가됩니다. 피해량·회복·보호막·에너지·재사용 제한·보상은 변경하지 않았습니다.

현재는 **기존 초상화와 문양의 컷인 연출**입니다. 캐릭터 몸의 신규 동작 프레임, 기술별 투사체·타격 순서 연출, 음성·고유 효과음과 실기기 성능 검수는 후속입니다.

8인 비교는 같은 컴포넌트를 배치한 검토용 갤러리이며, 게임에서 8개의 컷인을 동시에 표시하는 기능은 아닙니다. 정지 캡처를 위해 움직임을 줄인 상태입니다. 실제 전투 화면은 검증용 계정이 서버에서 해린 궁극기를 실행한 결과입니다.

서버 134개(skip 0), 관련 PC·모바일 8개와 TypeScript/Vite 빌드가 통과했습니다. 새 서버 검사는 8명 모두 실제 엔진으로 궁극기를 처리해 캐릭터 ID·이름·속성·기술명이 맞고 원본 상태를 변경하지 않는지 확인합니다. 새 브라우저 검사는 8종 경로와 동작 이름의 구분, 기술명 잘림, 컷인 아래 버튼 입력, 기기 움직임 감소와 효과 끄기를 확인합니다. 실제 전투 검사는 서버 결과와 문양의 연결, 에너지 소비, 중복/재접속 무재생과 다음 행동을 검증합니다. 기존 전투 편성/교체/승리/도주 및 설정 저장·복원도 포함합니다. 전체 브라우저 46개 재실행이나 8인 모두의 실제 브라우저 전투 검증은 아닙니다. 기존 큰 Phaser 청크 경고와 실기기 FPS·메모리 검수는 남아 있습니다.
