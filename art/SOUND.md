# 확정 전투 효과음

[개발 계획 A1](../docs/NEXT-STEPS.md)의 기능을 연결했습니다. 기존 공통 전투 갱신음을 확정된 기술/판정에 맞는 합성 효과음으로 바꾸고, 보물·승리 알림과 파도 배경음은 유지합니다. 사인파·삼각파와 짧은 음높이 변화로 만든 원본 소리이며 캐릭터의 말소리는 후속 작업입니다.

## 선택 규칙

새로 확정된 한 라운드에서 자신의 기술을 우선하고, 없으면 자신에게 온 적 기술, 그다음 동료 기술 한 건을 선택합니다. 승리 라운드는 기술 대신 승리 패턴을 선택합니다. 빗나감·회복·보호막·상태 기술 실행을 구분하며 공격은 실제 기술 속성을 사용합니다. 상태 기술 소리는 상태이상 부여 성공을 뜻하지 않습니다. 여러 기술을 행동 순서대로 재연하는 기능은 아닙니다.

최초 조회/새로고침, 중복·이전 버전, 같은 라운드의 협동 선택/대기, 여러 라운드를 건너뛴 복구와 과거 승리 상태에서는 새 소리를 요청하지 않습니다. 준비·행동 불가 자체를 공격음으로 만들지 않습니다. 결과를 새로 확정한 때에만 재생 요청하며 서버 계산·난수·피해·보상은 바꾸지 않습니다.

## 조작과 자원

- 신뢰할 수 있는 실제 포인터/키보드 입력 뒤에만 오디오 컨텍스트를 생성합니다. 합성 DOM 입력이나 소리 요청 이벤트만으로 자동 재생을 열지 않습니다. 브라우저의 오디오 정책을 따르며 지원되지 않으면 게임은 소리 없이 유지됩니다.
- 기본 음소거와 저장한 음량을 유지합니다. 음소거·음량 0·탭 숨김 때 활성/예약 음을 중단하고 컨텍스트를 멈춥니다. 돌아왔을 때 건너뛴 효과음을 쌓아 재생하지 않습니다. 배경 파도는 기존 환경 효과 설정을 따릅니다.
- 요청 간격 100ms와 합성음 최대 6개를 적용합니다. 새 화음 전체가 한도를 넘으면 추가하지 않아 일부 음만 잘리는 화음과 발음 수 초과를 막습니다. 혼잡/차단 상태에서는 요청이 생략될 수 있습니다.
- 음 종료 때 노드 연결을 정리하고 화면 종료 때 리스너·소스·컨텍스트를 정리합니다. 새 서버 API/DB/타이머나 런타임 오디오 파일 다운로드는 없습니다. 소리 설정은 그래픽 품질/움직임 감소와 독립적입니다.

## 미리듣기

[13종 효과음 WAV](previews/battle-sounds.wav)는 실제 재생과 같은 합성기로 오프라인 렌더링한 검토용 자료입니다. 22,050Hz 모노, 약 8.45초이며 아래 순서대로 0.65초 간격으로 재생합니다. 저장 음량 100의 마스터 배율을 사용하고 파도 배경음은 넣지 않았습니다. 게임에서는 파일을 다운로드하지 않고 직접 합성합니다.

| 순서 | 소리 | 음색 |
|---|---|---|
| 1–6 | 물·불·바람·번개·얼음·자연 공격 | 상승 물방울·낮아지는 불꽃·상승 바람·짧은 번개·높은 결정·따뜻한 잎 |
| 7–10 | 회복·보호막·상태 기술·빗나감 | 상승 화음·안정된 두 음·부드러운 두 음·짧은 하강음 |
| 11–13 | 보물·승리·공통 알림(호환용) | 기존 알림 계열 유지 |

## 확인과 남은 범위

서버 146개(skip 0), 관련 PC·모바일 10개와 TypeScript/Vite 빌드가 통과했습니다. 새 단위 5개는 음색의 구분/파형 입력 범위·잘못된 요청·6속성/지원/빗나감·초기/중복/대기/구형/지연 응답·승리 우선·협동 관점 선택과 상태 불변성을 확인합니다.

브라우저에서는 실제 Web Audio 노드로 입력 전 무음, 합성 입력 거부, 주파수/음색, 음량·음소거·탭 숨김, 예약 음 취소·복귀 무누적, 100ms 간격과 6음 제한, 종료 후 재생 금지를 검사합니다. 같은 합성기의 미리듣기 13구간 모두 유한한 비영 신호이며 샘플 피크가 0.2 미만인지 확인합니다. 이 수치는 디지털 샘플 범위이며 물리적 음압이나 실기기 청취 검수 수치는 아닙니다.

실제 전투 검사는 물/회복 요청, 초기·중복·이전 응답·새로고침 무재생을 확인합니다. 네 브라우저 협동에서는 선택 대기 중 무음과 라운드 확정 때 클라이언트마다 한 패턴을 요청하는지 확인합니다. 전투 완료·기존 설정 저장/복원도 포함하며 전체 브라우저 50개 재실행은 아닙니다. 실제 스피커/헤드폰 청취·믹스, 브라우저별 기기 오디오 정책과 캐릭터 음성은 후속 검수/산출물입니다.
