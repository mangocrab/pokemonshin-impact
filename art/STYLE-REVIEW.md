기준은 2026-11-03 사용자가 첨부한 8인 전신 시트입니다. 저장소의 [캐릭터 원본](source/heroes.png)과 같은 구성이며, 작은 머리와 긴 팔다리의 성인 비례, 얇은 색선, 부드러운 셀 음영과 그라데이션, 직물·금속의 섬세한 표현을 기준으로 검토했습니다. 단순히 청색·금색 팔레트만 같다고 화풍이 일치한 것으로 판단하지 않았습니다.

## 렌더링에서 함께 수정한 문제

원본을 바꾸어도 NPC를 고정된 가로·세로 크기로 늘이면 성인 체형이 다시 짧고 넓게 보입니다. 월드 아트는 원본 비율을 유지하면서 지정 영역 안에 맞추도록 변경했습니다. NPC는 최대 56×86, 여행자는 공통 셀 92×92로 표시하며 이름표도 위로 옮겼습니다. 새 야자수의 앵커는 밑동 중앙에 맞췄습니다.

길어진 NPC의 머리를 자르지 않도록 월드 시트의 열마다 실제 투명 행 간격을 읽습니다. 이동 시트는 공통 셀과 원점을 유지하고, 이동 거리·정지·벽·순간이동·움직임 감소의 기존 규칙을 사용합니다. 서버 충돌·지역 접근·상호작용·월드 권한·전투 수치는 변경하지 않았습니다.

화풍 판단은 원본과 적용 화면의 시각적 검토입니다. 자동 테스트는 화풍이 완벽히 같다는 판정을 내리지 않으며, 프레임 경계·이미지 표시·비율·다운로드 예산·게임 동작을 검증합니다. 이번 수정은 공통 여행자 대상이며, 캐릭터 8명의 개별 탐험 아바타·더 많은 중간 동작·개별 노멀맵·정교한 투영 그림자는 남아 있습니다.

PNG 6종을 보존하고 브라우저는 WebP 6종 합계 1,978,596바이트(약 1.89MiB)를 사용합니다. 2MiB 예산과 기존 14개 마이그레이션을 유지합니다. 인코딩 설정은 [아트 가이드](README.md#최신-화풍-수정)에 기록했습니다.

## 검증

서버 테스트 116개(skip 0), 관련 PC·모바일 브라우저 테스트 16개와 TypeScript/Vite 빌드가 통과했습니다. 브라우저 검사는 8명 초상화와 프레임 여백, 새 전투 배경 디코딩·적 그림·실제 전투/도주, 네 방향 보행·벽 앞 정지·터치·움직임 감소, 방문자 동기화·초대/복귀, 설정 저장, 로그인, NPC 대화/부탁, 제단 퍼즐·지역 해금·선물 획득을 포함합니다. 기존 브라우저 36개 전체를 이번 배치에서 다시 실행한 것은 아닙니다.

실제 적용 화면을 검토한 뒤 길의 직사각형 명암과 모래·잔디·해안의 거친 경계도 보정했습니다. 기존 좌표에서 색과 높이의 전이를 부드럽게 섞고 경로의 음영을 낮췄습니다. 서버가 판단하는 지형이나 충돌 경계는 유지했습니다. 빌드의 기존 Phaser 청크 크기 경고와 실기기 성능 검수는 남아 있습니다.
