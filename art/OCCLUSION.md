# 높이를 고려한 2.5D 가림

기존 바닥 실루엣 그림자에 **다른 물체의 표면이 빛을 받는지 판단하는 수광 마스크**를 추가했습니다. 건물·야자수·제단을 가림체로 사용하고, 여행자·방문자·NPC와 월드 그림의 표면에 높이별 그늘을 표시합니다. 원본 PNG/WebP, 서버 충돌·이동·보상·월드 권한은 유지합니다.

## 계산 방식

- 그림의 발 위치를 바닥으로 보고, 픽셀의 세로 위치에서 표면 높이를 근사합니다. 각 픽셀에서 좌상단 햇빛 방향으로 선을 보내 가림체와 만나는지 검사합니다. 따라서 발은 그늘인데 머리는 햇빛을 받는 상태를 표현할 수 있습니다.
- 건물은 벽과 3단 지붕의 상자 볼륨, 야자수는 줄기 상자와 수관 타원체로 근사합니다. 제단은 기단·양쪽 기둥·상부 보를 나누어 열린 공간을 막힌 벽처럼 취급하지 않습니다.
- 5개 방향의 선을 가중 합산해 그림자 가장자리를 부드럽게 합니다. 자신의 볼륨은 제외해 원본에 이미 그려진 자체 명암을 중복해서 덮지 않습니다.
- 결과는 원본 알파로 자른 별도의 작은 마스크로 표시합니다. 배경이나 투명한 여백을 직사각형으로 어둡게 하지 않으며, 원본 채색과 노멀맵도 바꾸지 않습니다.

가림 볼륨은 **시각 표현용 근사 모델**입니다. 실제 충돌 데이터로 사용하지 않습니다. 표면은 세워진 2D 그림으로 보고 계산하므로 정밀한 3D 메쉬, 창문별 내부 공간, 실제 지형 고도, 광원별 그림자 지도/PBR과는 구분합니다. 이번 가림체는 건물·야자수·제단이며 모든 인물이나 상자를 서로 가리는 입체 물체로 만든 것은 아닙니다. 기존 바닥 투영은 계속 함께 사용합니다.

## 설정·갱신·비용

- 고품질에서 그림자를 켜면 적용합니다. 동적 조명 끄기와는 독립적입니다.
- 낮은 품질에서는 수광 마스크를 생성하지 않고 기존 바닥 투영과 접촉 그림자를 유지합니다. 그림자를 끄면 두 기능을 모두 숨깁니다.
- 발 위치·크기·프레임·가림체 상태가 같으면 결과를 재사용합니다. 위치 변화는 약 15Hz로 제한하고 보행 프레임 변화는 즉시 갱신합니다. 입장·재접속 시 카메라를 복원 위치에 맞추어 초기 추적 이동을 줄였습니다.
- 가림체의 투영 범위를 먼저 검사합니다. 그늘 후보가 없는 물체는 원본 픽셀을 읽거나 마스크 텍스처를 만들지 않습니다.
- 원본 알파는 최대 128px 프레임별 캐시로 공유합니다. 마스크는 필요한 물체마다 한 장만 사용하고 오브젝트가 제거되면 텍스처도 정리합니다. 숨김과 부모 컨테이너를 따릅니다.
- 추가 이미지 다운로드와 DB 변경은 없습니다. 기존 WebP 6종 약 1.89MiB, 2MiB 예산과 14개 마이그레이션을 유지합니다. 마스크·캐시·GPU 복사에는 별도 메모리가 필요하며 실기기 성능 인증은 후속입니다.

## 검증 결과

서버 테스트 131개(skip 0), 관련 PC·모바일 22개와 TypeScript/Vite 빌드가 통과했습니다. 브라우저 검사는 새 가림 효과 외에도 기존 노멀맵·바닥 그림자, 보행, 방문자, 4인 협동 전투, 설정·NPC·탐험·로그인을 포함합니다. 전체 브라우저 40개를 모두 재실행한 것은 아닙니다. 소프트웨어 GPU 기반 검증이며 실제 모바일 기기의 성능 인증과 정밀 재질/지형 그림자는 후속 작업입니다.

## 화면 범위와 반복 자원 검증 (2026-11-03)

수광면의 월드 경계가 활성 카메라 범위에 들어올 때만 알파를 읽고 마스크를 계산합니다. 화면 밖으로 나가면 표시를 숨기고 기존 캐시를 유지하며, 다시 들어오면 위치·프레임·가림체 상태에 따라 재사용하거나 갱신합니다. **가림체는 화면 밖에서도 계속 검사**하므로 화면 밖 건물이나 수관이 화면 안 인물에 드리우는 그늘을 유지합니다. 원본 아트·바닥 그림자·노멀 아틀라스 생성 방식과 서버 규칙은 변경하지 않았습니다.

같은 그림자 설정을 다시 적용할 때에는 모든 수광 마스크를 강제로 다시 계산하지 않습니다. 실제로 껐다가 켜는 전환에는 즉시 갱신을 유지합니다. `screenReceivers`는 마지막 갱신에서 카메라 범위와 겹친 수광면 수, `maskBuilds`는 해당 렌더러 수명 동안의 누적 계산 횟수입니다. 기존 `masks`는 생성되어 캐시에 남아 있는 개수이므로 화면 밖으로 나가도 바로 줄지 않을 수 있습니다. 인물이 제거되면 그 인물의 마스크 텍스처는 정리하고 공유 프레임 알파는 재사용합니다.

별도의 두 프레임 검증 장면에서 실제 Phaser 텍스처 등록 수와 계산 횟수를 확인했습니다. 전체 게임의 프레임/재질 개수나 GPU 메모리 측정값은 아닙니다.

| 검증 상태 | 마스크 계산 누계 | 임시 마스크 텍스처 등록 수 |
|---|---:|---:|
| 처음부터 화면 밖 | 0 | 0 |

| 인물 12회 생성·제거 완료 | 14 | 0 |

마지막에는 원래 텍스처 개수로 복원되고 공유 알파 두 프레임만 유지됩니다. 실제 초대·복귀 검사도 방문자 오브젝트/접촉 그림자 정리를 계속 검증합니다. 실제 게임에서 같은 설정 저장 시 계산 횟수가 유지되고, PC·모바일 모두 화면 밖 수광면을 제외하는지도 확인했습니다.

관련 PC·모바일 14개와 TypeScript/Vite 빌드가 통과했습니다. 기존 노멀/그림자·가림·저품질/고품질·네 방향 보행·방문자·4인 협동과 새 캐시 검사를 포함합니다. 고정 위치의 PC·모바일 노멀/그림자 캡처는 이전 [바닥 그림자 마감 화면](LIGHTING.md#바닥-표시-순서와-부모-상태-2026-11-03)과 파일 내용이 같았습니다. 부분 그늘 장면도 확인했습니다. 전체 브라우저 44개와 서버 테스트는 이번 배치에서 재실행하지 않았습니다. 서버 테스트 목록은 기존 133개를 유지하며 실기기 FPS·RAM/VRAM 측정은 별도입니다.
