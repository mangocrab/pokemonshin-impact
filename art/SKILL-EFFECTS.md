# 서버가 확정한 기술 효과

라운드 전후 HP 차이로 기술의 명중 여부를 추정하지 않고, 서버가 실제로 시도한 기술의 기록을 표시합니다. 각 대상의 그림 영역에 6종 속성 표식·기술 이름·공격/회복/보호막/기술 실행 구분을 더했습니다. 빗나감은 별도 글자로 표시하고 타격 광륜은 숨깁니다. HP·에너지·상태 목록은 기존 위치에 유지합니다.

## 기록과 의미

`BattleState.skillCues`는 마지막으로 처리한 라운드의 선택적 표시 메타데이터입니다. 서버가 명중 판정을 한 자리에서 라운드, 사용자 역할/캐릭터, 실제 대상, 기술 ID/이름, 속성·분류·명중 여부를 기록합니다. 로그 문자열을 파싱하거나 클라이언트의 선택만으로 생성하지 않습니다. 추가 난수 판정, 피해·상성·상태·에너지 계산 변경은 없습니다. 기존 JSON 전투 상태에 저장하므로 DB 마이그레이션 14개를 유지합니다.

- `hit`는 **명중 판정만** 뜻합니다. 상태이상의 확률·면역·저항 판정 성공을 뜻하지 않습니다. 상태 기술에는 “기술 실행”을 표시하고 실제 상태 변화는 기존 상태 목록/결과 표시와 전투 기록을 따릅니다.
- 준비 시작, 행동 불가, 대기·방어·교체에는 실행하지 않은 기술 효과를 만들지 않습니다. 준비가 끝나 실제로 사용한 때에는 기록합니다. 아이템·반동·지속 피해·패시브 회복을 일반 기술로 추정하지 않습니다.
- 회복·보호막은 실제 사용자에게 표시합니다. 다른 플레이어의 자기 회복을 자신의 캐릭터에 붙이지 않습니다. 협동 공격은 “협동”으로 구분하며 같은 캐릭터 여러 명의 공격도 기록에서 합치지 않습니다. 적의 단일/광역 공격은 각 플레이어가 실제로 받은 대상만 자신의 화면에 표시합니다.
- 다음 한 라운드의 결과에만 연결하고, 기록된 라운드와 대상 ID를 확인합니다. 초기 조회·새로고침·중복/이전 버전·같은 라운드의 협동 대기·여러 라운드를 건너뛴 응답과 다른 캐릭터를 향한 기록을 재사용하지 않습니다. 이전 저장에 이 필드가 없으면 표식 없이 기존 결과 표시를 유지합니다. 강제 교체에서는 지난 기록을 지웁니다.

현재 효과는 **확정된 라운드의 요약**입니다. 여러 행동을 하나씩 재연하는 타임라인이나 기술별 투사체·치명타 연출은 아닙니다. 기존 HP 숫자도 라운드 전후의 순변화이며 개별 타격 피해량이 아닙니다.

## 화면과 설정

공격에는 속성 표식과 부드러운 광륜, 회복에는 점선 테두리, 보호막에는 두꺼운 수호 테두리, 상태 기술에는 파선 테두리를 사용합니다. 대상마다 최근 2개 기술을 표시하고 나머지는 개수와 “전투 기록” 안내를 남깁니다. 전체 서버 전투 로그는 유지합니다. 입력을 가로막지 않으며 기존 결과 표시와 함께 2.2초 후 제거됩니다.

움직임 줄이기에서는 표식과 글자를 정지시킵니다. 저품질/환경 효과 끄기에서는 광륜을 숨기고 기술 이름과 판정 구분을 유지합니다. SVG/DOM 구성 자체를 생략하는 방식은 아닙니다. 원본 일러스트와 WebP 6종 1.89MiB는 유지하며 추가 이미지 다운로드는 없습니다. 전투 상태의 표시 메타데이터와 클라이언트 코드가 추가됩니다.

## 검증

서버 141개(skip 0), 최종 관련 PC·모바일 12개와 TypeScript/Vite 빌드가 통과했습니다. 새 단위 7개는 명중/빗나감·원본 상태 불변·준비/행동 제한·회복/보호막·상태 면역·동일 캐릭터 4인·협동 자기 회복/광역 피격·구형/중복/대기 응답·교체 대상을 확인합니다.

새 브라우저 검사는 6속성 표식, 지원/상태/빗나감, 표시 개수 제한, 글자 폭·입력 통과, 움직임 줄이기/효과 끄기를 확인합니다. 실제 전투 검사는 서버의 물 기술 기록과 표시 연결, HP 영역을 가리지 않는 배치, 새로고침/중복 무재생과 저품질을 검증합니다. 4인 협동 검사에는 실제 API 응답의 자기/동료 기술 구분과 라운드 일치를 추가했습니다. 기존 전투/궁극기/편성/승리·협동·설정 복원도 포함하며 전체 브라우저 48개 재실행은 아닙니다.

작성 중 잘못 들어간 스타일 내용을 복원하고 새 스타일만 다시 적용한 뒤 최종 검사를 통과했습니다. 기존 큰 Phaser 청크 경고, 실기기 성능 검수와 신규 캐릭터 동작·기술별 투사체/행동 순서·음성은 후속입니다.
