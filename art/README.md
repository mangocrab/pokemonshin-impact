# Solara · 아트 가이드

최신 사용자 지정 방향은 첨부한 8인 시트의 **성인 비례·얇은 색선·부드러운 채색을 사용한 서브컬처 판타지 RPG**입니다. 전체 검토와 수정 내역은 [그림체 검토 기록](STYLE-REVIEW.md)에 정리했습니다. 이전 동화풍 혼합에서 맑은 청색·남색·금색, 정교한 애니메이션풍 얼굴·판타지 의상·빛 표현으로 전환했습니다. 이 디렉터리는 새로 제작한 원본과 아트 작업 기준을 보관합니다. 정적 일러스트·월드 오브젝트·공통 궁극기 컷인과 탐험 여행자의4방향 정지/걷기12프레임을 연결했습니다. 월드의 개별 프로시저럴 노멀맵과 실루엣 투영 그림자도 연결했습니다. 출전 캐릭터별 탐험 아바타·수작업 재질 노멀·캐릭터별 고유 전투 동작은 남아 있습니다.

## 화풍과 배치

- 사파이어 하늘·투명한 청록 바다·아이보리 모래·선명한 초록 잔디와 청색 지붕, 얇은 색선·부드러운 셀 음영·차분한 금속 반사와 직물의 주름을 사용합니다. NPC와 여행자의 큰 머리/짧은 팔다리 SD 비례는 성인 비례로 교체했습니다. 종이/수채화 질감은 새 시트에서 제거했습니다. 캐릭터는 속성별 머리색·의상·장신구로 구분합니다.
- 메뉴·전투는 새 판타지 의상의8명 전신 일러스트를 사용하고 맵은 작은 여행자/주민 스프라이트를 사용합니다. 현재 여행자 아바타를 출전 캐릭터에 따라 바꾸는 기능은 없습니다.
- 지도와 장식은 서버 지형을 따릅니다. 아트 변경 때문에 충돌·상호작용 좌표·방문자 권한·보상·캐릭터 능력치를 바꾸지 않습니다. 쉼터 발밑은(1050,675), 새 야자수는 밑동 중앙에 앵커를 맞춥니다. 월드 그림은 가로·세로를 별도로 늘이지 않고 원본 비율을 유지해 배치합니다. Y정렬과 그림자 설정을 유지합니다.
- 원래 해안 지형 이미지는 x1570에서 자르고 다리(y760~840)/안뜰을 기존 접근 판정과 맞춥니다. 지형 타일 경계는 샘플링 여백과 거울 반복으로 완화합니다.
- 고품질 지형은 새 디퓨즈 아트와 기존 높이 기반 노멀맵으로 실제 조명을 계산합니다. 월드의 여행자·NPC·건물·오브젝트에도 프레임별 프로시저럴 노멀 데이터를 연결했습니다. 실루엣을 바닥에 투영한 부드러운 그림자와 작은 접촉 그림자를 함께 사용합니다. 생성 방식, 품질 옵션과 2D 투영의 한계는 [노멀맵과 그림자](LIGHTING.md)를 참고하세요.
- 야자수 흔들림·파도·입자·걷기 프레임은 움직임 감소 설정을 따릅니다. 여행자는4방향을 각각 그린 프레임을 선택하며 좌우 반전을 사용하지 않습니다. 정지하면 마지막 방향의정지 프레임을 유지합니다.

## 내보내기

```bash
# 원본 아트 또는 아틀라스 프레임을 수정할 때만 필요합니다.
# Python3와 Pillow가 필요하며 일반 npm 설치/빌드/실행에는 필요하지 않습니다.
python3 scripts/export-art.py
npm run build
```

스크립트는 원본을 이동하거나 덮어쓰지 않고 WebP 인코딩과 프레임 메타데이터를 생성합니다. 투명 프레임 경계를 읽고 명목 격자 근처의 실제 투명 간격으로 행을 구분합니다. 지형 경계에는8px 여백을 두며 원본 그림은 재배치하지 않습니다. 다음 행의 모자 등이 위 프레임에 섞이지 않도록 인접 프레임 간 투명 여백도 검사합니다. 결과는 `client/public/art/*.webp`, Phaser용 `*.json`, React용 `client/src/art-manifest.ts`입니다. 세 파일 묶음의 프레임이 일치해야 합니다. `Art.tsx`는 명시적인SVG clipPath로 프레임 경계를 자릅니다. viewBox의 여백만으로는 가로로 긴 새 포즈에서 다른 행의 캐릭터가 비칠 수 있으므로 이 처리를 제거하지 않습니다. 변경 후 내보낸 파일도 함께 커밋합니다.

현재 브라우저 아트 6종의 합계는 1,978,596바이트(약 1.89MiB)입니다. 여행자 시트는 344,700바이트, 전투 배경은 145,404바이트입니다. 미로그인 시작 화면은 키 비주얼382,044바이트를 사용하고, 로그인 후 맵/메뉴는 월드·지형·여행자·캐릭터 시트를 사용하고 전투 진입 시 전투 배경을 추가로 읽습니다. 최초 다운로드 합계2MiB를 회귀 기준으로 사용하며 PNG 원본은 다운로드하지 않습니다. WebP는 캐릭터 메뉴와 전투에서 같은 URL을 공유하고 Phaser는 맵 시트를 한 번 읽습니다. 메모리/실기기 성능 인증 수치는 아닙니다.

## 확인과 다음 순서

아트 계약 테스트는 실사용 캐릭터/주민/적의 누락, 이미지 경계, Phaser/React 프레임 일치, WebP 형식과 다운로드 예산을 검사합니다. 새 PC/모바일 테스트는8명 실제 보유 캐릭터를 전환해 서로 다른 프레임을 확인하고 맵/뽑기/전투 아트·실제 도주 행동을 검증합니다. 기존 설정·움직임 감소·협동·탐험·상자·전투 회귀를 모두 유지합니다. 실제SVG를 캔버스로 렌더링해 여백의 이웃 프레임 노출이0인지 검사합니다. 새PC/모바일 시작 화면 테스트는 키 비주얼 디코딩·입력란 화면 내 배치·회원가입→로그아웃→재로그인을 실제로 확인합니다.

사용자가 정한 다음 순서는 **아트 마감 → 추가 콘텐츠 → 밸런스**입니다. 아트 단계의 잔여 작업은 출전 캐릭터별 탐험 아바타/동작 프레임, 수작업 재질 노멀과 정밀 메쉬/지형 가림, 전투 배경/기술·궁극기 연출, 실기기 화면·로딩 검수입니다. 이를 정리한 뒤 새 콘텐츠와 마지막 난도/경제 조정을 진행합니다. 기존 밸런스 보고서를 새 아트나 전체 콘텐츠의 완성 판정으로 사용하지 않습니다.

## 전투·이동 연출 1차

서버가 확정한 전투 스냅샷을 비교해 순HP·보호막 증감, 상태이상 부여/해제, 출전 교체를 표시합니다. 궁극기의 실제 에너지 소비를 확인한 뒤 기존 일러스트에 속성6종의 색상과 공통 컷인 구성을 적용합니다. 피격 반응·결과 표시·컷인은 입력을 가로막지 않으며 효과는2.2초 뒤 정리합니다. 첫 로딩·새 전투·중복/이전 버전·여러 라운드를 건너뛴 복구에서는 과거 연출을 재생하지 않습니다. 개별 타격/치명타·상태이상 틱마다의 이펙트를 표현하는 전투 이벤트 타임라인은 아직 없습니다.

자신과 방문자의 여행자 그림은 서버 위치가 실제로 바뀔 때4방향 걷기 프레임을 선택합니다. 막힌 지형에서 입력만 유지하거나 순간이동·월드 전환할 때는 걷는 모습을 재생하지 않습니다. 아래4방향 시트가 이전 정적 그림의 반전/상하 움직임을 대체합니다. 최신 시트는 SD 비례를 제거하고 성인 체형으로 다시 그렸습니다.

계정 및 기기의 움직임 줄이기는 걷기·피격·컷인·HP 보간을 멈추고 결과 글자를 정지 상태로 유지합니다. 낮은 품질에서는 컷인 초상화와 광륜을 생략하며 전투 계산·선택에는 영향을 주지 않습니다. 전용 음악/음성·캐릭터마다 다른 궁극기 애니메이션·수작업 재질 노멀·정밀 메쉬/지형 가림과 실기기 검수는 후속 작업입니다. 기존 WebP 예산과 마이그레이션은 유지합니다.

## 탐험 여행자4방향 시트

공통 여행자 한 명의남/서/동/북 각정지1포즈와걷기2포즈를 새로 그렸습니다. 기존 파란 단발·밀짚모자·크림색 블라우스·청록 선원 칼라·소라 가방을 유지합니다. 가로3칸·세로4칸의 원본PNG를 보존하며 WebP 344,700바이트를 추가로 내려받습니다. 월드 시트의 이전 정적 여행자 프레임은 다른 원본을 훼손하지 않도록 보관하지만 탐험 렌더링은 새 시트를 사용합니다.

걷기 순서는정지→첫발→정지→반대발입니다. 발동은 입력이 아니라 서버가 허용한 변위이며 이동 거리로 보행 위상을 갱신합니다. 마지막 방향을 유지해 정지하고, 순간이동은 걷기로 재생하지 않으며 월드 준비 시 남쪽 정지 자세로 초기화합니다. 계정/기기 움직임 감소에서는 방향만 바꾸고 해당 방향 정지 포즈를 유지합니다. 저품질에서도 같은 시트와 서버 검증을 사용합니다.

내보내기는 원본 픽셀을 옮기지 않습니다. 각 프레임의 투명 여백을 메타데이터로 잘라내되 Phaser의trimmed/sourceSize/spriteSourceSize에공통362×362셀과 위치를 기록합니다. 모든 프레임이 92×92 월드 크기와 같은 원점을 유지해, 큰 보폭 프레임을 정지 포즈 크기로 늘리거나 발 위치를 프레임마다 다시 맞추지 않습니다. 현재2발 루프는 초기 보행이며 더 부드러운 중간 동작·대각선 전용 포즈·8명 고유 탐험 아바타는 후속입니다.

자동 검사에서는12프레임 고유 영역·경계·공통 크기·모든 방향의 프레임 순환·정지/벽/순간이동/움직임 감소를 검증합니다. 실제PC/모바일 브라우저가 Phaser 이미지에 지정한 프레임을읽어 각방향의두걷기포즈·정지·터치·설정 저장 후 복원을 확인합니다. `.game`의읽기 전용data-traveler-frame/data-visitor-frames는 선택된 프레임 이름만 기록하며 명령이나 계정/전투 상태를 노출하지 않습니다.

## 최신 화풍 수정

[전체 아트 검토](STYLE-REVIEW.md)에서 원본과 실제 적용 화면을 함께 확인할 수 있습니다. WebP 내보내기는 캐릭터·키 비주얼의 기존 설정을 유지하고, 새 월드/여행자는 RGB 품질 88·알파 품질 65, 지형/전투 배경은 품질 80을 사용합니다. 원본 PNG는 변경하지 않는 인코딩 설정이며 전체 2MiB 예산을 유지합니다. 현재 저작 도구는 Pillow 12.3.0이며 `alpha_quality` 지원이 필요합니다. 일반 npm 빌드와 실행에는 Pillow가 필요하지 않습니다.

성인 NPC가 길어진 월드 시트는 열마다 실제 투명 여백을 읽어 행을 구분합니다. 다른 열의 제단이나 야자수 높이 때문에 사람의 머리가 잘리지 않도록 프레임 경계를 따로 계산합니다. NPC는 최대 56×86 안에 비율을 보존하고, 여행자는 공통 셀 92×92로 표시합니다. 충돌과 상호작용 좌표는 변경하지 않았습니다.

## 월드 조명과 그림자

[프레임별 노멀맵과 실루엣 그림자](LIGHTING.md)를 적용했습니다. 원본 아트는 그대로 유지하고, 월드/이동 24프레임의 표면 데이터를 런타임에 생성해 같은 프레임 좌표에 연결합니다. 추가 WebP나 Pillow 실행은 필요하지 않습니다. 조명과 그림자는 각각 끌 수 있으며 낮은 품질로 시작하면 오브젝트 노멀 아틀라스를 만들지 않습니다.

## 높이별 수광 가림

[2.5D 수광 가림](OCCLUSION.md)을 추가했습니다. 건물·수관·제단을 시각용 볼륨으로 근사해, 다른 물체의 표면이 높이에 따라 빛을 받는지 계산합니다. 원본 알파로 자른 별도 마스크를 사용하며 저품질에서는 생성하지 않습니다. 정밀 3D 메쉬와 실제 지형 고도를 처리하는 그림자 지도는 후속 범위입니다.

바닥 그림자는 높이에 따라 흐림을 나누어 발밑은 또렷하고 먼 부분은 부드럽게 마감했습니다. 비정사각 프레임의 두 축 축척을 보정했으며, [적용 화면과 검증 범위](LIGHTING.md#바닥-그림자-경계-마감-2026-11-03)를 보관합니다.

인물·상자의 바닥 그림자를 본체의 Y 정렬에서 분리해 다른 인물 위로 덮이는 문제를 수정했습니다. 부모의 숨김/투명도와 방문자 제거를 반영하며, [픽셀 겹침 검사와 적용 화면](LIGHTING.md#바닥-표시-순서와-부모-상태-2026-11-03)을 기록했습니다.

수광 마스크는 카메라에 들어오는 물체만 준비하고, 화면 밖 가림체가 드리우는 그늘은 유지합니다. 같은 설정을 다시 저장하면 캐시를 재사용하며, [카메라 복귀·12회 생성/제거 검증](OCCLUSION.md#화면-범위와-반복-자원-검증-2026-11-03)을 기록했습니다.
